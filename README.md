# ANDAR — API y planificador (repo MarsWalk-v3)

**ANDAR** · *Astronaut Navigation & Data-Assisted Routing* · Safe walks on Mars, with a rover one step ahead. Team Trinity.

Backend del proyecto para el reto *Interplanetary Survival Guide: Martian Map* (NASA Space Apps 2026): convierte datos
abiertos de NASA del cráter Jezero en capas de terreno y rutas seguras a pie, y sirve el asistente de voz del HUD.
El frontend vive en [`trinity-nasa-team/MarsWalk-web`](https://github.com/trinity-nasa-team/MarsWalk-web).

> El repositorio conserva el nombre de trabajo `MarsWalk`; el proyecto se presenta como **ANDAR**.
